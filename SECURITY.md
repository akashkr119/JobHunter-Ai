# Security Policy

## Supported Versions
The latest version of JobHunter-AI receives security updates.

## Reporting a Vulnerability
If you discover a security vulnerability, please report it privately to the project maintainer instead of opening a public issue.

Include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

## Disclosure Policy
Reported vulnerabilities will be reviewed, validated, and fixed as quickly as possible. Public disclosure should occur only after a fix is available.

## Security Best Practices
- Keep dependencies up to date.
- Do not commit secrets or API keys.
- Use environment variables for credentials.
- Regularly review third-party packages for vulnerabilities.
